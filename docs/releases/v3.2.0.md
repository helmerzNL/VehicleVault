> 🤖 *Note: This is an AI-generated release note summarizing the release (`v3.2.0`) of VehicleVault.*

**VehicleVault v3.2.0** is a major community and accessibility release designed for self-hosters and public demonstrations:

---

### 🌟 1. 1-Click Guest & Proef Sandbox Mode
- **Zero-Barrier Trial Sandbox:** Visitors can explore VehicleVault immediately via **`Probeer Proefmodus (1-Click)`** on the login screen or by opening any URL with `?guest=1`, `?proef=1`, `?invite=...`, or `?token=...`.
- **Full-Featured Sandbox Session:** Guest users can add test vehicles, log fuel fill-ups, scan receipts, configure tire sets, and explore TCO analytics in their own isolated sandbox.
- **1-Click Permanent Account Conversion:** A persistent, non-intrusive floating trial banner allows guests to preserve everything they created. Clicking **`Bewaar Mijn Account`** prompts for an email and password and instantly converts the guest session into a permanent user account without data loss.
- **Admin Control:** Administrators can enable or disable guest trial access with a toggle in **Settings → Users** or via the `ALLOW_GUEST_ACCESS=false` environment variable.

---

### 🛡️ 2. Hardened Reverse Proxy Single Sign-On (SSO)
- **Zero-Trust Header Guard:** Secure reverse proxy authentication supporting **Pangolin**, **Authelia**, **Authentik**, and **Traefik**.
- **Admin UI SSO Toggle:** Dedicated toggle in **Settings → Users** to enable/disable reverse proxy authentication at runtime.
- **IP & Subnet Protection:** Verification of proxy connections restricted strictly to loopback (`127.0.0.1`, `::1`) and RFC 1918 private subnets.

---

### 🎨 3. Adaptive Theme & Language Auto-Detection
- **Zero-Flash Theme Detection:** Automatically adapts to system dark or light mode preference before UI render.
- **Browser Language Localization:** Automatically defaults to Dutch (`nl`) or English (`en`) based on browser language headers.

---

### 🏎️ 4. Cockpit Telemetry HUD & High-Precision Fixed Costs
- **Animated Cockpit HUD:** Real-time speed gauge, live distance meter, and active telemetry diagnostics.
- **High-Precision Fixed Costs:** Prorated monthly, quarterly, and annual fixed costs calculations across insurance, road tax, and inspections.
