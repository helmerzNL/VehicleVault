## 🌟 What's New

### 🏠 1. Multi-Tenant Per-User Home Assistant Connections
- **Isolated Telematics per Household (`user_ha_configs`):** Home Assistant is no longer restricted to a single global server instance. Every registered user (including standard accounts) can navigate to **Settings → Home Assistant** or their **Profile** to configure their own Home Assistant URL and personal Long-Lived Access Token.
- **Dedicated Sensor Discovery:** Selecting vehicle odometer entities dynamically queries the Home Assistant instance of that vehicle's owner.
- **Smart Background Telematics Sync:** Automated odometer synchronization queries each vehicle against its respective owner's Home Assistant credentials. User A's vehicles and User B's vehicles sync cleanly and independently without collision or credentials leakage.
- **Self-Service Connection Testing:** Every user can test their Home Assistant connection with instant status and version feedback.

### 👑 2. Super-Admin Server Governance & Fleet Overview
- **Server Users Directory:** Super-Admins have exclusive access to **Settings → Server Gebruikers (Admin)** to view all registered accounts across the server.
- **Real-Time Login & Activity Audit:** Review exact timestamps for **last login** (`last_login_at`) and **last user activity** (`last_active_at`), account registration dates, vehicle counts, and shared vehicle access.
- **Global Role Assignment:** Effortlessly switch user roles (`Super-Admin`, `Gebruiker`, `Chauffeur`) with a single click.
- **Fleet-Wide Overview:** Super-Admins can toggle **Toon Alle Voertuigen (Admin)** on the Vehicles page to inspect all vehicles on the server with clear owner tags (`Gedeeld (user@example.com)`), while private documents and invoices remain strictly confidential to their respective owners.
- **Protected Server Controls:** Server-critical features (Database Backups, Reverse Proxy switches, AI model keys) are automatically hidden from non-admin accounts.

### 🔑 3. Direct Co-Driver Invitations & Vehicle Delegation
- **Invite Any Email:** Vehicle owners can open the **Delen (Share)** modal on any vehicle and enter any email address (e.g. spouse, partner, family member).
- **Auto-Provisioning & Onboarding Link:** Non-registered recipients are automatically provisioned as standard users. VehicleVault generates a 1-click invite onboarding URL (`/login?invite=...`) that owners can copy and send via WhatsApp or email.
- **Custom Access Levels:** Assign co-drivers as **Editor / Bewerker** (full permissions to log fuel fill-ups, charging, trips, and service records) or **Viewer / Toeschouwer** (read-only access to history and TCO).
- **Owner Revocation:** Vehicle owners can modify permissions or revoke access at any time.

### 🛡️ 4. Seamless Reverse Proxy Single Sign-On (Pangolin, Authelia, Authentik)
- **Automatic Page Load Session Minting:** When navigating through an authenticated reverse proxy (such as Pangolin SSO), VehicleVault reads identity headers (`Remote-Email`, `Remote-User`, etc.) on initial page navigation (`GET /`) and immediately issues hardened HTTP-only session cookies (`refresh_token` and `vv_token` with `Path=/`). Users land directly in their dashboard without hitting a redundant login screen.
- **Real-Time Diagnostics (`/proxy-debug`):** Added a root-level diagnostic endpoint to inspect incoming proxy headers, client IP, and proxy authentication status in real time.

### 🎨 5. Adaptive Visitor Experience
- **Zero-Flash Theme Detection:** Automatically detects system dark or light mode preference (`prefers-color-scheme`) before rendering.
- **Browser Language Auto-Detection:** Automatically displays Dutch (`nl`) or English (`en`) based on browser language headers.
